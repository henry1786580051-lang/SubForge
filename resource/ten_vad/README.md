# TEN-VAD Runtime

This directory contains the macOS universal native runtime from
[`TEN-framework/ten-vad`](https://github.com/TEN-framework/ten-vad), commit
`22a3bcd4509d0faaa8eef4881e8af5f39c178950`.

SubForge uses TEN-VAD only for conservative post-ASR timestamp validation.
See `LICENSE` and `NOTICES` in this directory for the upstream terms.
