# 工作区质量规范与验收记录

更新：2026-09-08。此文区分实现、自动测试、实际应用验证与发布门槛；未覆盖项不能按通过处理。

## 设计约束

- 系统玻璃用于窗口外壳和导航，编辑内容保持稳定、不透底的阅读表面。
- 常用配置先于高级参数：源语言 → 识别引擎 → 当前模型 → 说话人 → 硬件。源语言只保留一个入口。
- 模型使用可读名称、精度变体与可用状态；路径放入详情。当前模型不要求先展开整个分组。
- 工作区选项目前会保存为后续默认值，标题区明确说明。真正的“仅本次任务覆盖”需要单独的数据设计，不能只改文案。
- `WorkspaceControls.tsx` 管理分组、开关、任务操作；`InspectorDisclosure.tsx` 管理展开、箭头和隐藏焦点。新页面复用组件，不再复制整段实现。
- 分组圆角 11 pt，控件 8 pt，悬停反馈内缩 3/4 pt。长文撑高整行，背景、焦点和点击区域使用同一容器。
- 悬停约 130 ms，面板约 240 ms；进度用 transform。减少动态效果时关闭位移和过渡。禁止用总体百分比推断真实任务阶段。
- 错误提示保留到用户关闭或开始新的操作；成功通知可自动消失。两类消息均提供朗读语义。

## 本轮实现

| 优先级 | 问题 | 处理 |
| --- | --- | --- |
| P0 | 未保存字幕仍可能按磁盘旧文件处理 | 统一任务入口阻止，并显示先保存的说明，不自动覆盖原文件 |
| P0 | 保存过程中继续编辑，被误标为已保存 | 保存快照与文档版本校验；晚到的旧文档保存结果被忽略 |
| P0 | 实时处理期间编辑、删除、撤销与任务结果竞争 | 数据层阻止这三类修改，编辑入口与相关按钮同步禁用 |
| P1 | 错误状态没有可见出口 | 主工作区增加持久错误提示和关闭操作 |
| P1 | 源语言重复、模型隐藏太深 | 移除重复入口，模型摘要直接展示，高级参数单独折叠 |
| P1 | 保存缺乏持续反馈 | 文件名、未保存、保存中、任务处理中状态；支持保存清空后的文档 |
| P1 | 键盘无法直接编辑字幕 | 原文和译文单元格可聚焦，回车编辑，输入带明确名称 |
| P1 | 进度暗示错误的阶段完成情况 | 移除推算阶段，显示后端消息与范围受限的可访问进度条 |
| P2 | 取消缺少等待状态 | 取消中反馈和重复操作禁用 |
| P2 | 公共控件实现散落 | 提取公共组件，清除废弃的 inspector summary 样式 |

## 开发检查台

开发模式启动前端后，左下角“控件检查”打开 `WorkspaceGallery`。包含 260/312 pt 两种宽度、长说明、开关、禁用、选择器、嵌套折叠及模拟取消等待。只用于受控 UI 状态，不连接真实任务；生产模式不会挂载。仍须用打包 App 验证原生外壳。

- 本轮 43 项前端测试、28 项字幕后端回归通过；前端构建、针对变更文件的 ESLint、安装包签名校验通过。
- 自动测试覆盖保存与撤销、保存并发、旧文档回写、清空保存、未保存处理阻止、处理中的编辑保护，以及既有任务时序与模型展示回归。

## 整体审查修复（2026-09-08）

本轮审查的五项问题已修复。上传副本首次保存后转到应用数据目录的 `saved-subtitles/<唯一目录>/<文件名>`，前端同步实际路径；原生打开的文件仍原位保存。导入采用全局事务，读取期间不更新路径且禁止启动任务、保存和编辑；运行任务、未保存修改或其他文件操作存在时拒绝替换。保存锁跨页面有效。

任务预览不再设置保存基线，取消后保留未保存提示。配置写入串行执行，失败保留已确认的工作区选项；任务等待写入屏障，未解决的写入错误阻止启动。

验证：54 项前端、43 项后端/桌面测试通过，生产构建通过。打包预览实际经编辑器上传入口导入独立样本，两次编辑保存到同一个持久路径；源样本保持不变，退出后保存结果仍在。真实收费转录/翻译与网络故障的端到端演练未执行，相关时序使用受控回归测试验证。
