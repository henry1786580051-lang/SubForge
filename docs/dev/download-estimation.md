# 模型下载进度与估时（2026-09-14）

## 行为

Whisper.cpp HTTP 下载及 Hugging Face / faster-whisper / 对齐 / 说话人模型下载统一回传 `download` 遥测。界面在转录配置内显示已下载量、总大小、速度与预计下载剩余时间，不再以固定 5% 代表真实下载进度。

- 每秒采样；最近约 15 秒的吞吐窗口叠加 4 秒时间常数的指数平滑。
- 最初 4 秒、恢复连接及进度回退后重新预热，不显示旧 ETA。
- 10 秒未收到新传输字节显示等待网络响应，撤下速度与 ETA。
- 缓存和续传初始字节计入完成量，不计入网络速度。
- 未知总大小时不显示百分比或 ETA，使用不定进度动画；遵守减少动态效果设置。
- 近期速度变异系数超过 0.5 时显示较宽时间范围。这是保守的展示区间，并非经统计校准的置信区间。
- 下载百分比最多 99%；校验是独立状态，只有任务成功才达到 100%。失败、取消、完成和校验清除旧下载遥测。
- 单个页面同时只跟踪一个手动模型下载，避免重复点击覆盖当前任务状态。

## 实现边界

Hub 适配器只在可取消的独立下载进程内安装，观察锁定依赖 huggingface-hub 0.36.2 的文件下载和 HTTP/Xet 进度上下文。保持原库的缓存、鉴权、文件筛选、并发、版本与重试逻辑；通过原有仓库信息请求取得文件大小，没有额外逐文件 HEAD 请求。HTTP 回调粒度从默认 10 MB 调整到 64 KB，避免慢速连接长时间不回报进度。退出时恢复库属性。

多文件进度通过共享计数器汇总，避免进度消息队列阻塞取消。网络传输计数独立于缓存完成量。没有可用的字节回调时不捏造速度；未来升级 Hub 时必须重跑适配器测试。已安装 App 尚需单独更新才会使用本次变更。

此次范围是应用内模型下载；CLI 视频下载继续使用 yt-dlp 的原有行为。无 LLM 调用、无 token 成本。

## 验证

覆盖恒速、预热、缓存、续传、未知大小、停滞恢复、速度下降、进度回退、多文件汇总、嵌套进度回调、取消后的库恢复、终态清理以及 HTTP 下载至校验的状态链路。

真实网络冒烟测试仅下载 Systran/faster-whisper-tiny 的 config.json（2,249 字节），验证子进程下载与已知总量回传，临时目录自动清理。它不代表多 GB 下载估时精度的实网评测。
