# 设置与诊断日志页面更新

2026-09-05，在专业通透工作区的基础上统一两个辅助页面。

## 设置

- 顶部玻璃分类栏取代第二层侧栏，提供通用、LLM 服务、语音识别、字幕处理、文件与存储五类。
- 外观移入通用分类，通过三个窗口预览选择跟随系统、浅色或深色。
- 表单使用分组行结构，标签、说明与控件分栏；较窄窗口改为上下排列。保留原有保存、模型检测和下载逻辑。
- 分类切换使用短暂淡入；沿用系统减少动态效果、降低透明度与对比度处理。

## 诊断日志

- 用任务列表和详情双栏替代密集表格，突出文件名、请求错误、耗时和用量。
- 常见阶段使用中文名称；零用量显示为 0，缺失数据单独显示。
- 请求、参数与响应正文按展开状态渲染，避免预先格式化整个任务的全部正文。
- 补齐加载占位、搜索无结果、服务读取失败与重试、无请求明细状态。
- 查询及详情使用请求序号阻止过期响应覆盖新选择；清除日志需在页内再次确认。
- 原有日志文件、内容、搜索接口与任务算法保持不变。
