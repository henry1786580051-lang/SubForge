# 专业通透界面 · 2026-09-05

采用原生玻璃操作层、实色字幕阅读层。保留 React 编辑器、原有断句翻译和文件处理流程。

## 实现

- macOS 原生 `NSToolbar` 与玻璃样式 `NSButton`：导入、侧栏、处理选项、任务取消、字幕导出。侧栏按钮位于窗口左侧，其余操作位于右侧；窗口标题展示文件名，副标题展示任务状态。工具栏后续精修见 `toolbar-polish-20260905.md`。
- macOS 26 使用系统玻璃按钮，旧版系统使用原生圆角按钮；原生工具栏安装失败时保留网页工具栏。其他平台使用网页界面。
- 网页侧栏、导出浮层和选中字幕操作条使用统一的通透材质；字幕表格保持实色，右侧设置去掉重复卡片边框，按功能分组。
- 侧栏和处理选项使用短过渡；收起的处理选项同时设为 `inert`，退出键盘焦点顺序。导出浮层支持 Escape 关闭并自动聚焦关闭按钮。
- 深浅色与系统模式同步至原生窗口；读取并监听 macOS 降低透明度、减少动态效果、增强对比度偏好，同步至网页区域。网页同时提供对应媒体查询回退。
- 桌面桥只接受限定的显示状态和固定命令。主线程按钮通过 WKWebView 异步派发事件，避免在 AppKit 回调中同步等待网页执行。
- 顶部导入与 ⌘O 支持视频、音频和字幕。不可导出时禁用导出；没有运行任务时隐藏取消按钮。

## 验证

- 前端 32 项测试、ESLint、生产构建通过；Python 启动和桥接测试通过。
- macOS 26.6.2 实际日志确认 `toolbar=True`、`liquid_glass=True`。
- 实际应用验证：统一入口导入字幕、动态文件标题、处理选项收起、原生导出打开网页选项并保存 SRT、编辑中 ⌘S 保存、⌘Z 撤销、选中字幕操作条、原生和网页深色同步、全屏与普通窗口恢复。
- 最终安装包的 27 个前端文件与构建输出逐个校验一致；原生工具栏代码和导出的 5 条字幕内容校验通过。
- 桌面打包运行检查覆盖服务启动、FFmpeg、本地 MLX Metal、PyTorch MPS、WhisperX 和 Pyannote 导入；没有执行付费模型请求。
- 旧版系统材质回退与辅助功能偏好处理已实现；本轮没有切换系统辅助功能设置，也没有在旧版 macOS 上实机验证。
