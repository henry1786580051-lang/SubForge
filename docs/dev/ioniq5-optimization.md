# IONIQ 5 样本驱动优化（2026-09-17）

## 已落地

- 为 Level / 2 charger、parking / cameras、sound system test / song、Bose / systems 增加带来源的边界风险规则；大小写变化不绕过检查，正常句末不触发。
- 从本片重复出现至少两次的完整“名称 + 数字 + 可选配置后缀”提取保护短语。只在可靠逐词对齐、同说话人、时长与字数约束允许时移动边界；优先让名称留在已有修饰语后。既不猜测近音名称，也不把词的时间重新均分。
- 本地语义检测新增充电级别、Limited 配置名、剩余续航、行动主体反转、保护对象反转、否定结果被改为疑问等候选；沿用已有局部语义复核流程。
- “not placeful”仅标记当前空间含义缺少证据，提示核查 ASR 与上下文，不确定一个替代英文词。

## 成本与边界

结构与候选检测不调用 LLM，不扩大每个翻译批次的通用提示。命中候选可能触发现有局部复核，因此不是绝对零新增 token。模型仍可能拒绝或不充分修复，不能将检测覆盖率当作最终翻译准确率。

第 596/597 条成句文本已经删除重复词与口头语，与原始逐词记录不同，本次保护逻辑拒绝重建这对字幕。需要后续提供清理后词级映射，不能强行恢复原始重复词。源字幕的句末留白可能在重建后收紧到最后一个词的结束时间；本轮验证词级时间未改变，不宣称完成听音对齐。

## 验证

新增 34 项测试，涵盖真实断句、原始词序和时间戳不变、幂等性、拒绝不完整对齐、已翻译字幕保护，以及语义检测的反例。完整回归和工具结果保存在 `artifacts/subtitle-audits/ioniq5-20260917/`。

GLM-5.3-flash 对 8 个实际候选进行提示安全性与语义抽查，共 1944 tokens；全部提示被评为安全，6条支持标记，322与390的布尔判断却和其改写解释不一致。它对35仍保留“实测”，229添加“脱离危险”，因此不直接采用其生成译文，也不视为端到端修复通过。

本次只修改算法与测试；用户三件套和已安装 App 未替换，没有整片重译、发布或生成新 App 副本。

## 后续全量验证

2026-09-17 已完成 GLM-5.3-flash 同参数端到端消融对照与全部 1451 条输出的匿名评审。结构保护可见改善，但否定结果被改为要求、跨条时间重复仍有漏检；不能将 GLM 的“严重疑点为零”视为真实零错误。详见 `artifacts/subtitle-audits/ioniq5-20260917/full-glm/全量测试报告.md`。两组流水线和评审共 1940889 tokens，源三件套未改动。
