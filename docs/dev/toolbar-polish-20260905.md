# 原生工具栏精修 · 2026-09-05

## 设计

导入、处理选项、导出使用独立的原生玻璃按钮。去掉组合玻璃底板，统一大号控件、13 点中等字重、14 点 SF Symbols 和至少 36 点点击高度，中文标题宽度按实际字体测量。侧栏开关移至窗口左侧，导出与前面的操作保持额外留白。

处理选项保留真实的开关状态和辅助功能语义。导出在已有字幕时突出显示，没有字幕时禁用；取消按钮只在任务运行时出现。按钮响应、玻璃材质和焦点反馈由 AppKit 绘制，布局容器不叠加额外材质。

## 构建修正

此前 PyInstaller 预编译启动程序标记为 macOS SDK 15.5，即使调用玻璃按钮 API，系统也没有完整采用新控件渲染。构建脚本现在在 SDK 26 或更新版本下，从经过 SHA-256 验证的 PyInstaller 6.20.0 源码编译本机架构启动程序，并按 SDK、架构和版本缓存。

PyInstaller 会为 Tk 兼容性把主程序 SDK 标记降至 Python 动态库的 SDK。SubForge 使用 AppKit，因此在组装主程序后保留实际编译启动程序所用的 SDK 版本，并重新签名。当前应用经检查为 SDK 26.5，最低系统标记维持 11.0；这不代表所有依赖已经在 macOS 11 实机验证。

旧版系统使用原生圆角样式；使用旧 SDK 构建时保留标准启动程序。要获得 macOS 26 的完整系统视觉效果，需要使用 SDK 26 或更新版本构建。
