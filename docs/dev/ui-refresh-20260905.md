# macOS 工作区界面更新

本次保留 React / Next 与原生文件桥接，集中调整工作流布局、可读性、外观和反馈。转录与翻译算法未改动。

- 工作流仅在左栏导航，工具栏显示当前文件和任务状态。
- 导入空状态只显示素材入口；读入文件后显示摘要和下一步。
- 字幕为主工作区，处理选项可以隐藏；运行中可从顶部取消任务。
- 任务按钮置顶，高级引擎、模型、硬件和翻译要求通过折叠项展开。
- 字幕正文 15px，固定时间列；编辑、删除、合并支持最多 30 步撤销，新文档和任务结果重置历史。
- ⌘O 导入、⌘S 保存、⌘Z 撤销、⌘, 设置；文本输入保留原生编辑快捷键。
- 外观支持跟随系统、浅色、深色，仅在本地保存外观偏好。
- 页面和选项区域使用短入场过渡；遵循系统减少动态效果偏好。
- 44 枚 Solar 图标离线内置，构建时校验名称，不请求图标服务。授权说明随应用打包。
- 空数据显示“未检查”；译文覆盖率只说明是否存在译文，不能代表语义精校通过。

验证记录保存在 `artifacts/ui-refresh-20260905/`。本次更新不代表已完成 App Store 签名、沙盒及审核准备。
