## 已采用的修复

| 原边界 | 缺陷 | 当前行为 |
| --- | --- | --- |
| 27–28：`Almost a million / Berliners voted…` | 原规则只处理数字写法与小写后续词，漏掉完整数量片段与大写复数人口名词 | 在原数字依赖检测中识别这种有限结构；逐词回放合成完整的“近百万柏林人投票……”一句 |
| 83–84：`…built around / me who share…` | `around` 既可能是副词，也可能带宾语，原规则漏掉明确的宾格代词证据 | 仅有明确宾格代词时增加依赖信号；逐词回放将 `around` 移到下一条，与 `me` 同条显示 |

数量规则要求左边整体是数量片段，不能因 `We raised a million / Berliners…` 而重新打开已完整的分句。其新增范围限于大写、以 s 结尾的复数名词；没有声称覆盖所有数量名词结构。

介词规则仅覆盖少量可兼作副词的介词，要求后面是 `me/him/us/them`，排除句末标点、分句标点和 `Me, I…` 式话题重启。`it/you/her` 存在主宾格或所有格歧义，不据此强判。

两者都复用现有类型化诊断、风险权重和边界归一化器，不改提示词、不增加模型调用环节、不新增翻译重试校验器。

- 原始逐词回放保留全部词文本、词序、词起止时间、逐词说话人及时间来源，二次归一化结果一致。
- 第 27–28 条原始逐词说话人从 3 切到 1，间隔 41 ms。既有强依赖规则允许在此短间隔内修复；逐词说话人保留，合并后的字幕级说话人按既有规则选择。没有声称字幕级说话人或字幕块起止时间完全不变；重分组后的字幕边界来自原有词时间。

- 新增 40 项测试，覆盖两组真实词时间、独立语法正反例、完整分句、独立副词、长停顿、说话人伴随约 500 ms 停顿、两侧已有译文及重复运行。
- Python 全量：2789 通过、11 跳过；Ruff、Pyright、差异检查通过。

未执行 GLM 或其他在线 LLM，也未重新翻译整片。此次没有增加提示词或 API 阶段，但断句变化可能影响既有调用的分组与后续校验，因此未测量、也不宣称总 token 降幅或全片翻译质量提升。
