## 问题与结果

Elantra 第 25 条中的 `245-35ZR19` 在原始逐词字幕里只有 382 ms，处理后的结束时间是 1:49.172，而原音频一直说到约 1:50.0。已有的保守句尾补长不足以弥补上游错误。

## 实现

- 用受约束的轮胎规格语法识别 `245-35ZR19`、`245/35R19`、`245/35 ZR19` 等形式。宽度、扁平比、结构和轮圈尺寸共同确认类型，普通年份、区间、型号不走这条规则。
- 英语强制对齐前展开为口语形式，随后按字符范围恢复原始显示文本与 token 边界。不改字幕文字。
- 多词口语映射要求首尾文字和首尾时间都得到支持，不能仅凭前半部分匹配就接受一个过早的结束时间。
- 数字时长保护按已识别规格的口语长度给出有上限的时长预算；普通数字仍保留原有规则。两个显示 token 的规格也保留相应预算。
- 仅在复合规格后存在 220–3200 ms 间隙时尝试原音频局部校准。上下文最多 12 秒；要求对齐分数至少 0.70、规格起点与下一词起点偏差不超过 180 ms、词序完整且结束不跨下一词。只接受有声学支持的句尾延长，不填满真实停顿。
- 增强仍用于识别文字，校准读取原音频。使用直接对齐器而不是分块转录包装器，不额外运行 Whisper 解码或在线 LLM。
- WhisperX 缓存键加入对齐版本，避免复用旧的词级对齐结果。

原始历史错误的中间数据不足以唯一还原某个触发步骤。本次修复同时覆盖复合规格展开、时长截断，以及增强音频引起的残余句尾偏移，已用真实音频贯穿验证。
