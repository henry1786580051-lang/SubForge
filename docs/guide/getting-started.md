# 快速开始

SubForge 当前桌面版包含三个连续但互不强制跳转的工作区：导入媒体、语音转录、字幕处理。

## 1. 配置模型

在设置中选择 ASR 引擎。Apple Silicon 推荐 WhisperX 的 MLX 转录模型和对应语言的 forced alignment 模型；多人模式还需要 Community-1。Windows 可选择 WhisperX、FasterWhisper、Whisper.cpp 或云端 Whisper API。

使用“测试当前配置”确认模型、运行环境与路径均可用。

## 2. 导入媒体

在导入页选择本地音频或视频。应用会读取时长、音轨和媒体信息，但不会修改源文件。

## 3. 转录

选择源语言、音轨、批处理大小和是否启用多人模式，然后开始转录。单人模式可选择 DeepFilterNet 音频增强；多人模式默认保留原始音频，以减少弱声说话人丢失。

转录过程中会实时显示已生成字幕和时间轴质量指标。完成后可保存或导出原始 SRT。

## 4. 断句与翻译

导入已有字幕或直接使用转录结果。选择智能断句、翻译、目标语言和 LLM 配置后开始处理。任务会保留恢复文件，完成后执行空译文、占位文本、错位和重复检查。

成品字幕可在编辑器中修改、保存和导出。当前版本只输出字幕文件，不烧录或重新编码视频。
