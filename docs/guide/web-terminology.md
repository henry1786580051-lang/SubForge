# 联网术语核实

在设置的“LLM 服务”中选择 DeepSeek 官方接口并配置 API Key，即会在 LLM 翻译前自动核实疑难术语，无需独立开关。推荐模型名为 `deepseek-flash`。其他服务商和非 LLM 翻译不调用该联网接口；旧配置中的联网开关不再生效。

适用场景包括新车型、产品配置名、专业术语和疑似听写错误的专有名词。应用先生成原文摘要与术语表，再挑选需要核实的名称，优先查询厂商或技术提供方的资料。搜索能返回正文时直接复用，缺失时才抓取网页。

## 原文和证据边界

- 引用必须来自实际返回的网页正文，不能只凭搜索摘要、模型记忆或听起来合理的猜测。
- 同品牌但不同部件的资料不能互相证明，例如中控台的引用不能用来核实尾门名称。
- 已核实的词条只作用于包含对应原文短语的字幕，不允许把别处的名称带入当前字幕。
- 网页作为参考数据处理，其中的命令或指令不执行。
- 不用网页参数替换视频说出的年份、排量、动力、价格或观点，也不修改原始英文字幕。无法确认的词条保持保守处理。
- 无法搜索或抓取时继续普通翻译，并在任务结果记录状态。任务结果的 `web_research` 字段保留来源、引用、接受的词条与请求计数。

## 次数、费用和缓存

每个任务最多进行 3 次搜索和 2 次抓取，不自动重试收费工具请求。按 2026-10-17 官方价格，工具费用上限约为 ¥0.025，模型提取和核实产生的 token 费用另计。HTTP 请求有超时、响应大小限制和取消检查。

搜索与抓取证据缓存 7 天，与普通模型响应缓存分开保存。缓存命中不发起对应工具请求，重复任务可能降低联网费用。关闭应用缓存时不读写该证据缓存。

自动核实时，少量搜索词会发送至 DeepSeek 搜索服务；上下文提取和证据核实使用当前 DeepSeek 官方凭据。不会把其他服务商的密钥发送至 DeepSeek。

官方说明：[搜索与抓取](https://api-docs.deepseek.com/zh-cn/guides/search/)、[模型名与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。搜索、抓取是独立接口，不需要将现有翻译请求改成 Responses API。

## 开发验证

可对已有双语 SRT 做同模型、同源字幕的有界 A/B 测试。输出必须放在独立目录，原文件不会覆盖。需要显式传入 `--live` 才会使用本机已保存的 DeepSeek 官方凭据并产生 API 费用：

```bash
.venv/bin/python scripts/evaluate_web_terminology.py \
  --source /absolute/path/example_processed.srt \
  --output artifacts/web-terminology-evaluation \
  --cues 1-24 --live
```

输出包括两组字幕、上下文、引用、请求日志和 `comparison.md`/`comparison.json`。既有翻译只作为参考，不等同于人工标准答案。默认抽取 24 条，最多 64 条；该测试不代表整部视频的所有字幕都已人工校对。
